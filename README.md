# Patawi Brewspace — Mobile Web App Prototype

**Patawi Coffee Roastery (Purwokerto, Jawa Tengah)**  
*Prototype Aplikasi Web Mobile E-Commerce & Management Dashboard untuk Proyek Mata Kuliah Digital Business.*

---

## 📌 Deskripsi Proyek
**Patawi Brewspace** adalah rintisan aplikasi mobile web (progressive web application) yang dirancang khusus untuk Patawi Coffee Roastery yang berlokasi di Purwokerto Utara, Kabupaten Banyumas. Aplikasi ini menggabungkan alur belanja pelanggan (*Customer Experience*) yang ramah pengguna dengan alur manajemen operasional sangrai & pengiriman bagi pemilik toko (*Admin/Owner Dashboard*). 

Proyek ini dikembangkan sebagai bentuk transformasi digital UMKM lokal, memfasilitasi pemesanan biji kopi berkualitas tinggi (*freshly roasted beans*) secara mudah, terstruktur, serta mendukung integrasi skema harga Member & Regular serta opsi pengiriman instan.

---

## 🚀 Fitur Utama

### 1. Customer Flow (Tampilan Pelanggan)
* **Home & Banner Promo:** Menampilkan hero promo *Batch Sangrai Baru*, jaminan sangrai segar (maksimal 7 hari), serta edukasi *cupping* & asal biji kopi.
* **Pencarian & Filter Interaktif:** Filter profil sangrai (*Light*, *Medium*, *Medium-Dark*) dan kategori metode seduh.
* **Katalog Produk Dinamis:** Menampilkan harga secara dinamis berdasarkan ukuran (200g, 500g, 1000g) dan tingkatan akun (*Regular vs Member*).
* **Checkout & Pengiriman:** Integrasi pilihan kurir (*GoSend Instant*, *Self Pick-Up*) dan kalkulasi otomatis ongkos kirim.
* **Pembayaran QRIS Real-Time:** Simulasi pembayaran instan via kode QRIS nasional lengkap dengan pengunggah bukti transfer.
* **Lacak Pesanan (Order Tracking):** Penjajakan status pesanan (*Verifikasi Pembayaran ➔ Diproses ➔ Pengiriman Kurir ➔ Selesai*).
* **Bottom Navigation Bar:** Footer navigasi 5 tombol (*Beranda, Katalog, Keranjang, Pesanan, Profil*) bergaya aplikasi e-commerce modern.

### 2. Admin & Owner Flow (Tampilan Manajemen)
* **Ringkasan Penjualan (Executive Metrics):** Informasi *Today's Sales*, status *Pending QRIS*, dan pesanan *Ready to Ship*.
* **Verifikasi Pembayaran QRIS:** Validasi bukti bayar pelanggan secara cepat (*Verify / Reject*).
* **Pengaturan Kurir (Courier Dispatch):** Fitur penugasan kurir otomatis (*Book GoSend Courier*) dengan simulasi *live status* driver (Contoh: Driver: Budi - H 1234 AB).
* **Manajemen Stok & Produk (Inventory Management):** Monitoring batas stok (*In Stock*, *Low Stock*, *Out of Stock*). Modal *form* untuk edit detail produk (Nama, Profil Roasting, Flavor Notes, Harga Regular/Member, Jumlah Stok).
